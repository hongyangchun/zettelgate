> 覆盖视频转写、课程、网页文章、书籍章节。方法论依据：Doto **Ch.2 参考笔记 / 批注前置（Marginalia）**、
> 路径 B（`references/doto/methods/doto-create_SKILL.md:46-84`）。
> 纳管于 2026-11-11，用户要求：**把 scholar bot 的视频转笔记能力收进知识库**。

---

## 0. 封装的是什么（边界先划清）

| 收进库里 ✅ | 留在链路边缘 ❌ |
|---|---|
| 转化**契约**：raw → 批注 → 参考笔记 → 判断 → 主笔记 | 下载 / 抓流 / ASR 二进制（downbit、baocut、浏览器抓流） |
| 批注模板、判断判据、页面格式、门禁诊断 | 平台 cookie、代理、命令行参数、转写耗时估算 |
| 「什么算一条合格的笔记」的一致口径 | `link-to-transcript` skill 里的路由判决与环境事实 |

理由：**能力要跨 Agent 一致，靠的是转化口径，不是把每台机器的下载脚本复制进库**。
边缘工具由 Hermes `link-to-transcript` / `knowledge-vault` 照旧负责；库只规定它们交出来的东西长什么样。

## 1. 现场盘点（2026-11-11 实测）

| 项 | 现状 |
|---|---|
| `raw/transcripts/` + `raw/articles/` | **109 份**全文，头部有 `source_url::` / `ingested::` / `sha256::`（`SCHEMA.md:7`） |
| `pages/笔记/` 视频笔记 | **79 页**，形态多为「开头试读 + `[[…全文]]` 链接」 |
| 批注层 | ⚠️ **基本为空** —— 有原文、有索引页，缺「我为什么在意这段」 |
| 主笔记转化 | 未形成稳定链路 |

**核心判断**：raw 全文**不是笔记**，是来源层；只有「要点摘录」的长篇视频页也不是主笔记，是**参考笔记**。
scholar bot 缺的那一环不是转写能力，是 **Doto 的批注前置**。

## 2. 转化链（五步，不可跳）

```
① raw 全文（不可变）
      ↓  只读引用，逐字摘句
② 批注 Marginalia   ← 目前缺的就是这一层
      ↓  按时间戳/页码组织，回答「为什么重要 / 同意吗 / 和谁相关」
③ 参考笔记（type:: 文献笔记 / 视频笔记，SCHEMA.md 范式）
      ↓  逐条判断：背后有没有一个值得独立的原创想法？
④ 不值得 → 保留参考笔记作阅读索引，到此结束
   值得   → 用自己的话重写成单一主张
⑤ 主笔记（type:: 原子笔记，ZETTEL.md 范式）→ zettelgate add
```

> `doto-create_SKILL.md:78-83`：「这段话背后有一个值得独立的原创想法吗？」
> **不要每段有感触的都转主笔记**（`doto-create_SKILL.md:254-255`）。
> 一个好标准：如果这条笔记未来三年你都不会再看，就别创建。

## 3. 批注模板（视频用时间戳，书籍用页码）

写在**参考笔记页内**，不新建独立文件；`raw/` 保持只读、不落批注。

```
## 批注

### 00:12:34 — <话题关键词>
> <逐字原文引用，来自 raw 转写稿；ASR 同音字已校对>

- 为什么重要：<这段解决了我的什么疑问 / 冲击了什么假设>
- 同意 / 不同意：<立场 + 理由>
- 与已有想法相关：[[已有页名]] — 为什么链     ← 暂无则写「（暂无）」，不要造断链
- 是否转主笔记：否（理由：只是背景信息） / 是 → 拟题「<声明式断言>」

### 00:28:10 — <话题关键词>
> ...
```

三条必答：**为什么重要 / 同意不同意 / 和哪些已有想法相关**（`doto-create_SKILL.md:71-77`）。
第四条是转化判据，把「值不值得」显式写下来，避免事后整页重读。

**AI 时代补注（2026-11-11，`PRINCIPLES.md` 第 5 节）**：转写、摘要、要点摘录都已可由 Agent 代劳，
整条链里**唯一不能外包的就是这一层「我怎么看这段」**。所以：
- 「同意 / 不同意」是主笔记 `## 单一想法` 段判断立场（stance）的原料，不是可省的格式项；
- Agent 可以起草批注，但**不得自行编造用户立场**；拿不准就写「待用户确认」；
- 不要把模型生成的要点摘录直接当批注入库 —— 那是合成文本，不是判断留痕（`doto_audit.py` D2 会标原创性风险）。

## 4. 判断判据（④ 那一步）

| 转主笔记 ✅ | 留在参考笔记 📦 |
|---|---|
| 能用自己的**完整句子**重述成一个主张 | 只是事实、数据、定义、背景 |
| 与已有想法能产生连接（延伸/对比/质疑/跨域） | 只是原文精彩，但没有我自己的东西 |
| 未来三年还可能再看、还能用 | 一次性信息，查得到即可 |
| 已能拟出**命题句标题** | 只能拟出话题标签（「关于XX」） |

拿不准就**留在参考笔记**。Doto 的原则是宁可少转，不要为了凑数把摘抄伪装成原创（诊断 D2 会标「降级为参考笔记」）。

---

## 5. 页面格式与登记

### 参考笔记（第 ③ 步）
- 落 `pages/笔记/`，properties 按 `SCHEMA.md`（`type:: 视频笔记 | 文献笔记`、`source::`、`author::`…）
- 必须含 `## 批注` 段；全文链接指向 `raw` 页（如 `[[XXX-全文]]`）
- 由既有 scholar-inbox-ingest 管线落盘；**新增页用 `zettelgate register` 登记** index/log + lint
- ⚠️ `raw/` 不可变：校对 ASR 同音字改在参考笔记的引用里，不改 raw 文件

### 主笔记（第 ⑤ 步）
- 按 `ZETTEL.md` 六要素写，`origin::` 指向**参考笔记页名 + 时间戳**，不是原始 URL
  （例：`origin:: [[哲学通识第64集]] 00:12:34 批注；与朋友 2026-11-11 的对话`）
- `zettelgate new` → 填写 → `zettelgate add`；Folgezettel ID 留空
- 按 `ZETTEL.md` 填 `claim_type::` / `verified::`（**可选**）：取值由第 ④ 步判断决定 —— 若主张来自推理类比，就别填 `true`；D16 会提示区分事实与推理
- 链接回参考笔记时写明「为什么链」；反向链接由 Logseq 自动形成

## 6. 门禁覆盖

| 检查 | 档位 | 说明 |
|---|---|---|
| 参考笔记的 `[[ ]]` 目标存在、`type::` 合法、index 有条目 | 硬 gate G1/G6/G7 | 沿用 `lint.py` |
| 视频/文献笔记缺 `## 批注` 段 | **诊断 D13** | 只提示，**不阻断** —— 79 页历史页不该一夜之间全变红灯 |
| 批注缺「为什么重要 / 同意不同意 / 关联」三要素 | 诊断 D13 | 启发式，允许误报 |
| 只有 `[[…全文]]` 链接、正文几乎为空 | 诊断 D13 | 提示补批注或降级 |
| 主笔记是否原创、是否单一想法 | 诊断 D1/D2 | 见 `PRINCIPLES.md` |

> **不批量回填 79 页历史笔记**（`doto-audit_SKILL.md:19-20`）。
> 报告列出缺口即可；哪天恰好用到某一页，再顺手补批注 —— 这就是「遇到再处理」。

---

## 7. 与两条写入路径的关系

- `CONTRACT.md` 路径 B（既有进料管线）继续按 `SCHEMA.md` 落参考笔记；**本文件给它补上批注层与转化出口**
- 路径 A（自己的想法）只接第 ⑤ 步的产物，走 `zettelgate add`
- 两路径在 `[[ ]]` 上互通：参考笔记 → 主笔记的 `origin::`，主笔记 → 参考笔记的「为什么链」，正是 Doto 的 reference → main 那条链

**一句话**：scholar bot 负责把视频变成**可读的原文 + 索引页**；这个库负责规定**什么时候它才算变成了一个想法**。
